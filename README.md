# 深夜の収支レビュー

マネージャーの桐生として、日曜の夜にパートナーの黒崎から収支と継続を詰められるチャットシミュレーター。
フィクションです。人物・会社・案件はすべて架空です。

## 動かす

```sh
npm install
npm run dev        # http://localhost:5173
```

- `http://localhost:5173/?fast` … 待ち時間が約1/12になる（動作確認用）
- `npm test` … エンジンのテスト（台詞データの整合性チェックを含む）
- `npm run build` … 型チェック＋本番ビルド（`dist/`）

## Vercel に公開

Vite のプロジェクトとして自動判定されるので、設定ファイルは不要。

```sh
npx vercel        # プレビュー
npx vercel --prod # 本番
```

GitHub に push して Vercel の管理画面から Import しても同じ（Build: `npm run build` / Output: `dist`）。

## 構成

| ファイル | 役割 |
|---|---|
| `src/data/rounds.ts` | 台詞と選択肢、数値の変化。**中身を変えるならここだけ** |
| `src/engine/night.ts` | 1晩の組み立て（導入 → 通常回＋メモ回＋28時＋電話＋会議中 → 締め） |
| `src/engine/read.ts` | 自由入力の読み取り（上から順に当たったものを採用） |
| `src/engine/state.ts` | ステータスと難易度、変化の計算 |
| `src/engine/ending.ts` | 結末・称号・適性の判定 |
| `src/ui/view.ts` / `src/main.ts` | 画面と進行 |

## 台詞を足すとき

`POOL` に1回分を足すだけで出るようになる。選択肢は3つで、だいたい次の型から組む。

| 型 | 信頼 |
|---|---|
| 数字＋打ち手＋期限 | +6〜+12 |
| 黙って行動する（`send: "file"` / `"none"`） | +8（メンタル0） |
| 正直だが策がない | 0〜+4 |
| 言い訳・外部要因のせい | -6〜-10 |
| 謝罪（`sorry: 1`） | -4（メンタル大） |
| 責任転嫁・越権の指摘 | -12〜-16 |

`npm test` は「どの回にも信頼が上がる手が1つはある」「選択肢は3つ」などを確認する。
